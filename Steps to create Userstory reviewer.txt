Steps to create Userstory reviewer agent:

Component 1:

Add the component "Manual Trigger"

Component 2: 

Add the component "HTTP Request"

Double click and open the component 

Set the below fields:

Method ----->Post
URL---->https://your.atlassian.net/rest/api/3/search/jql   (Replace your.atlassian.net with your actual jira URL)
Authentication--->General Credential type
General Auth type--->Basic Auth
Basic Auth--->click Create new credential and enter the username as email id and password is Jira API Key then click save

Enable the send body 
Body content type-->JSON
Specific Body--->Using JSON

Under JSON Value ,paste the below request body and replace your story key in jql value

For singe story:


{
    "jql": "key = \"TES-2\"",
    "fields": [
        "key",
        "summary",
        "description",
        "status",
        "reporter",
        "Acceptance criteria"
       
    ]
}

For multiple story from projects
{
  "jql": "project = Testleaf AND issuetype = Story",
  "fields": [
    "key",
    "summary",
    "description",
    "status",
    "reporter"
  ]}




Node 3:

Add Basic LLM Chain 

Double click and open the component

Source for Prompt (User Message) as Define Below from dropdown

Add the prompt (Prompt Template file) in the placeholder provided on prompt(user message)


Node 4:Groq Model


Under Basic LLM Chain you can find '+' symbol to add the model component .Click on + and add Groq Chat Model 

Double click and open the component

Parameters -->Credentials to connect with --Click the create new credential-->Add the Api key and click save .

Choose the model like llama-3.3-70b-versatile ., etc


Node 5: Send an Email 


Before setup the component you need to have a setup your gmail account with password:

Password is key created from google account to connect (not a normal password which is used by users)



Steps to create the password for gmail setup

https://myaccount.google.com/security

enable 2-Step Verification If it's not already enabled.

After enabling 2-Step Verification, search for App passwords or open the below link

https://myaccount.google.com/apppasswords

Enter App Name as "n8n" and app password will be created .Make a note of it 


Now go back and open the flow & Double click and open the component (Send an Email)

Under parameters 

Credential to connect with Click new credentials 

Enter user--Your mail id
Password --Key created from google account just now
Host--smtp.gmail.com


Make sure Port should be 465 and SSL/TLS should be enabled 
Click Save button


Operation --->Send 

Enter the from and to emails 

Subject :Userstory Review

Email format--Text

Text ---{{ $json.text }}

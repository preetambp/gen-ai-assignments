
Component 1:(Chat Trigger)

Click on +(Add a trigger) button to create the flow 

Click on chat on search box then select chat--->On new Chat event

Click on testchat or close the chat window (you will see chat trigger is created on flow page)


component 2:Basic LLM Chain

Click on +(Add a trigger) button

Click on chat on search box then select Basic LLM Chain

Select source for prompt and choose the option Connected Chat Trigger Node

Under the option Chat Messages (if Using a Chat Model) click Add prompt 

select Type Name or ID as "User"

Message type as Text

Under Message ,paste the prompt given in the "Test Case Generator -ICEPOT-Prompt" file


Component 3:Groq Model


Under Basic LLM Chain you can find '+' symbol to add the model component .Click on + and add Groq Chat Model 

Parameters -->Credentials to connect with --Click the create new credential-->Add the Api key and click save .

Choose the model like llama-3.3-70b-versatile ., etc 


Open Chat and give the userstory in chat window

Start generating the testcases
